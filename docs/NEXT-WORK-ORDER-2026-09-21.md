## Acceptance criteria for WO-01

1. Inventory identifies the correct Pages project, current serving URLs and all retained deployment/branch aliases; the currently reported 87 deployments are accounted for without assuming the count stays fixed.
2. Automatic main/preview publication is disabled and read back. Unrelated projects/builds remain unchanged.
3. Canonical and enumerated old deployment/branch URLs no longer serve old repository content; HTTP checks are interpreted alongside control-plane state. A custom 404 body or disabled build toggle alone is not sufficient proof.
4. Main/gear Worker version IDs, domains, bindings, Access configuration and DNS remain as intended; login and unauthenticated API denial still work. No order, balance or stock operation is used as a smoke test.
5. Evidence records exactly what changed, time, operator, irreversible artifacts removed and any residual reachable surface. No secrets/member records are placed in Git.
